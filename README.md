# Personal Site

Portfolio site — [jccifuentes.dev](https://jccifuentes.dev)

## Stack

- **Vite + React 19 + TypeScript**
- **Framer Motion** — scroll-triggered animations, spring cursor
- **Lucide React** — icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build    # production build → dist/
npm run preview  # preview locally
```

## Deployment

Deployed on Vercel. Every push to `main` triggers a new deployment.
